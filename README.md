# ぶいすぽ配信探索システム

「ぶいすぽっ！」所属メンバーの配信アーカイブ情報を集約し、メンバー・ゲーム・期間・キーワードなどから横断的に過去配信を探しやすくするWebシステムです。

## 背景

所属メンバーが増えるにつれて、YouTube上だけでは次のような探索が難しくなっています。

- 最近どのメンバーがどのゲームを配信しているのか知りたい
- 特定のゲームを遊んでいるメンバーを横断的に探したい
- 「以前このメンバーがこのゲームを配信していたはず」という過去配信を探したい
- チャンネル単位ではなく、所属メンバー全体を横断して配信を探したい

本プロジェクトでは、YouTubeそのものを置き換えるのではなく、**自分が使いたい軸で配信アーカイブを再探索できること**を目指します。

## 開発目的

このプロジェクトには、次の2つの目的があります。

1. 自分自身が継続して使える配信探索Webアプリを作る
2. 個人開発・就職活動用ポートフォリオ・IT技術の実践学習を兼ねる

実装を通して、フロントエンド、HTTP / REST API、バックエンド、RDB / SQL、外部API連携、バッチ処理、コンテナ、CI/CD、クラウド、ログ・監視、セキュリティなどを段階的に学びます。

## 開発方針

- 小さく動かしてから広げる
- 必要性が確認できていない技術を先に導入しない
- 単純な構成で問題を経験してから、それを解決するために技術を追加する
- テストしやすい構造を意識する
- Git / GitHubを積極的に利用する
- 原則として無料で開発・運用し、有料サービスは必要性と費用対効果を確認してから導入する
- 最終的には、利用規約等に問題がなければ外部公開できるWebアプリを目指す

## 現在のフェーズ

現在は **Phase 0: データソース調査・PoC** の準備段階です。

Webアプリ本体を実装する前に、外部サービスから次の情報を安定して取得できるかを確認します。

- 配信ID
- タイトル
- 配信者
- チャンネルID
- 配信URL
- 配信日時
- 配信時間または終了日時
- ゲーム / topic
- 配信種別・状態

特に、具体的なゲーム名をどのデータソースから取得するかを最優先で検証します。

## 想定しているMVP

現時点では、次のような機能をMVP候補としています。

- VSPO! JPの対象メンバーの配信アーカイブを集約
- メンバーによる絞り込み
- ゲーム / topicによる絞り込み
- 配信期間による絞り込み
- タイトルキーワード検索
- 配信一覧表示
- YouTube配信ページへの遷移

認証、お気に入り、視聴履歴、おすすめ、高度な全文検索などはMVPには含めません。

## 技術スタック候補

現時点の第一候補です。データソースPoC後に正式決定します。

- Frontend: React + TypeScript + Vite
- Backend: FastAPI + Python
- Database: SQLite（MVP）
- ORM / Migration: SQLAlchemy + Alembic
- Version Control / CI: GitHub / GitHub Actions

PostgreSQL、Docker、Redis、Queue / Worker、クラウド等は、必要になった段階で導入を検討します。
